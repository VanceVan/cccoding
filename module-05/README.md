## Selected topic
**Yard tool interface**, refined. The listed topic names a domain, not a problem, and the
Design Project Description separately flags the other listed option ("dexterity aid") as too
generic — so the narrowing is explicit and shown as a decision tree.

**Scoped application space:** independent residential yard maintenance by manual wheelchair
users with full upper-limb function, for tasks requiring a handheld powered tool
(string trimming, edging, hedge trimming, blowing) on soft, uneven, sloped turf.

**No solution is proposed** — the rubric explicitly rewards this.

## Candidate innovation parameters
- **P1** reaction-force path and stability margin (ISO 7176-1/-2 limits on a grade)
- **P2** seated reach and workspace envelope
- **P3** mobility while equipped (stow / decouple / quick release under fault)

## Core problem insight
Handheld powered yard tools assume a standing operator who reacts torque through stance and
body weight and repositions by stepping. A seated manual wheelchair user loses all three, and
— the sharper point — manual propulsion is itself a two-handed cyclic task, so holding a tool
consumes exactly the limbs mobility requires.
