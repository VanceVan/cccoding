# Module 4 — Application of Basic Anatomy and Biomechanics

**Course:** EN.585.617 Rehabilitation Engineering (FA26)
**Case:** Bilateral transtibial amputee; high-level systems design of a walking prosthesis (Part A)
plus adaptation for snowboarding (Part B).

## Deliverable
`Module_04_Assignment_Transtibial_Prosthesis.docx` / `.pdf` — 7 pages, Arial, 4 figures, 6 tables.

## Design assumptions
m = 60 kg, BW = 588.6 N, foot length 0.24 m, ankle height h = 0.07 m,
ankle-to-forefoot COP d = 0.13 m. All results scale linearly with body weight.

## Key results
| Quantity | Walking | Snowboarding |
|---|---|---|
| Peak resultant force | 716 N (1.22 BW) | 824 N carve (1.40 BW); 3532 N landing (6.0 BW) |
| Ankle moment | 83.6 N·m sagittal (1.39 N·m/kg) | 107 N·m frontal; 459 N·m landing |
| Pylon stress (30x2 mm) | 76.4 MPa | 417 MPa |
| SF on 6061-T6 (276 MPa) | 3.6 | **0.66 — yields** |
| SF on Ti-6Al-4V (880 MPa) | 11.5 | 2.1 |

The landing case is the governing structural result: the aluminium pylon that is comfortable for
walking fails under a snowboard landing, forcing a titanium substitution.
