# Module 2 — Formulating a Design Plan

**Course:** EN.585.617 Rehabilitation Engineering (FA26)
**Prompt:** Plan a project to add a retractable sun/rain awning to a best-selling electric wheelchair model.

## Deliverable
`Module_02_Assignment_Design_Plan.docx`

- **Part A** — solution-neutral need statement with supporting rationale
- **Part B** — design plan structured on the FDA design control waterfall (User Needs → Design Input →
  Design Process → Design Output → Verification → Validation → Design Transfer), with per-phase tasks,
  information to gather, design review structure, and objective exit criteria

## Traceability IDs used throughout
| Prefix | Meaning |
|---|---|
| `UN-n` | Critical user need |
| `DI-n.n` | Critical design input traced to a user need |
| `TA-n` | Technical aspect addressed in the design process phase |
| `VER-n` | Verification plan traced to a design input |
| `VAL-Qn` | Validation survey question traced to a user need |
