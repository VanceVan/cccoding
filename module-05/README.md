## Selected topic
**Yard tool interface**, refined. The listed topic names a domain, not a problem, and the
Design Project Description separately flags the other listed option ("dexterity aid") as too
generic.

**Scoped application space:** independent residential yard maintenance by manual wheelchair
users with full upper-limb function, using handheld powered tools on unimproved ground.

**No solution is proposed** — the rubric explicitly rewards this.

## Candidate innovation areas
- reaction-force path and the stability margin it leaves (ISO 7176-1/-2 on a grade)
- seated reach and working envelope
- mobility while equipped (stow / decouple / release under fault)
